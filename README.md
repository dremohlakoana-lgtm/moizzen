# 🏦 Moizzen

**Smart banking. Your way.**

Moizzen is a South African fintech platform featuring:
- 🎟️ Voucher deposits (1Voucher, BluVoucher, OTT)
- ➡️ Instant money transfers
- 🏦 Bank withdrawals via PayFast
- 📈 JSE stock investments
- 📱 Social media integration via Zarvibe

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- Database: PostgreSQL
- Payments: PayFast
- Media: Cloudinary
- Email: SendGrid
- Hosting: Render

## Run Locally
```bash
npm install
npm start
```

Open: http://localhost:3000
